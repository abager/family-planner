              Din HelloFresh refresh_token bruges til at hente denne uges menu. Tokenet varer 60 dage og opdateres automatisk.

              Find tokenet: Åbn HelloFresh i browser, åbn DevTools (F12), gå til Application → Cookies, find cookien apiV2Auth, og copy værdien af "refresh_token"
